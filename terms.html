HUB — условия использования

Обновлено: 16 ноября 2026

Назначение

HUB («Приложение») — частный инструмент одного автора для загрузки собственных видеороликов на собственные каналы YouTube. Приложение не предоставляет услуг третьим лицам и не является публичным сервисом.

Правила использования

  • Загружать можно только собственный контент либо контент, на который у вас есть права.
  • Использование обязывает соблюдать Условия использования YouTube и Условия YouTube API Services.
  • Запрещено использовать Приложение для массовых рассылок, накруток, спама и любого контента, нарушающего правила YouTube.

Доступ и токены

Доступ выдаётся по явному согласию владельца аккаунта Google. Согласие можно отозвать в любой момент на странице myaccount.google.com/permissions. Обработка данных описана в политике конфиденциальности.

Отказ от гарантий

Приложение предоставляется «как есть», без гарантий пригодности для конкретных целей. Автор не отвечает за возможные ограничения, блокировки или потерю данных на стороне YouTube, а также за последствия загрузки контента, нарушающего права третьих лиц.

Изменения

Условия могут обновляться; актуальная версия всегда доступна по этому адресу.
